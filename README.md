## Привет! Я Роман — Full-stack разработчик (Node.js)

Занимаюсь разработкой Telegram-ботов, Telegram Mini Apps, веб-интерфейсов и автоматизацией бизнес-процессов. Проектирую архитектуру с нуля: от клиентской части и базы данных до развертывания и настройки безопасности на Linux-сервере под ключ.

## Основной стек и навыки
* **Backend и Telegram API:** JavaScript (ES6+), Node.js, Express, grammY (`@grammyjs/conversations`), `node-cron`, REST API, Webhooks
* **Frontend и Mini Apps:** HTML5, CSS3, Vanilla JS, Telegram Web Apps API (интерактивные веб-панели и приложения внутри Telegram)
* **Базы данных и кэширование:** PostgreSQL, SQLite (`better-sqlite3`), Redis
* **Серверы, сети и DevOps:** Linux, Docker, Docker Compose, Nginx, Git, настройка фаерволов (`nftables`) и базовой сетевой безопасности

## Что я делаю
* **Telegram-боты любой сложности:** онлайн-запись, магазины, воронки продаж, системы рассылок, админ-панели и подключение платежных шлюзов.
* **Связка «Бот + Веб-интерфейс»:** разработка личных кабинетов и CRM-панелей в браузере или внутри Telegram Mini Apps на единой базе данных.
* **Интеграции и автоматизация:** связка ботов с внешними сервисами по API (Google Таблицы, CRM, AI-модели), фоновые задачи по расписанию.
* **Запуск под ключ:** упаковка проекта в Docker, настройка домена, SSL-сертификатов (Nginx) и защита сервера.
